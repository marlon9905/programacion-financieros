Antes de empezar, necesitas tener instalados estos dos programas:

Paso 01

Crear la carpeta del proyecto

Necesitas una carpeta donde guardar todo: el Excel, tus archivos .py y los gráficos que se generen.

1
Abre el Explorador de archivos

Ve a tu disco C: (o donde prefieras).

2
Crea una carpeta nueva

Clic derecho → Nuevo → Carpeta. Ponle un nombre simple, por ejemplo: PROYECTO-FINAL-FINANZAS

3
Pega el archivo Excel ahí

Copia el archivo dataset_cartera_creditos.xlsx (el que te envió el profesor) y pégalo dentro de esa carpeta.

Importante: Verifica que el nombre del archivo sea exactamente dataset_cartera_creditos.xlsx. Si Windows le puso algo como dataset_cartera_creditos (1).xlsx, renómbralo al nombre original.
4
Copia la ruta de tu carpeta

Haz clic en la barra de dirección del Explorador de archivos (arriba, donde aparece la ruta). Se selecciona el texto. Cópialo (Ctrl+C). Lo vas a necesitar en el código. Ejemplo: C:\PROYECTO-FINAL-FINANZAS

Tu carpeta debe verse así:
📁 PROYECTO-FINAL-FINANZAS
    📄 dataset_cartera_creditos.xlsx
Paso 02

Instalar las librerías

Python necesita 3 librerías que no vienen instaladas por defecto. Solo se instalan una vez.

1
Abre la terminal

En VS Code: menú Terminal → Nuevo terminal (o Ctrl+Ñ). Aparece un panel abajo.

2
Escribe estos 3 comandos, uno por uno: 
pip install pandas
pip install openpyxl
pip install matplotlib

Espera a que cada uno termine (dice "Successfully installed...") antes de escribir el siguiente.

¿Te sale error? Si dice 'pip' is not recognized, intenta con pip3 install pandas en vez de pip. Si sigue fallando, es porque Python no se agregó al PATH — reinstala Python y marca la casilla "Add Python to PATH".

Paso 04

Leer el Excel en Python

Escribe este código en tu archivo leer_datos.py:

import pandas as pd

# Leer la hoja "Creditos" del Excel
datos = pd.read_excel(r"C:\PROYECTO-FINAL-FINANZAS\dataset_cartera_creditos.xlsx", sheet_name="Creditos")

# Mostrar las primeras 5 filas
print("--- CRÉDITOS ---")
print(datos.head())

# Ver cuántas filas y columnas tiene
print(f"\nFilas: {datos.shape[0]}, Columnas: {datos.shape[1]}")

# Ver los nombres de las columnas
print(f"\nColumnas: {list(datos.columns)}")
¡Cambia la ruta! Donde dice r"C:\PROYECTO-FINAL-FINANZAS\..." pon la ruta de TU carpeta. Copia la ruta desde el Explorador de archivos y pégala ahí.

La r antes de las comillas es obligatoria — le dice a Python que las barras \ son parte de la ruta de Windows, no caracteres especiales.
▶
Ejecuta el código

Clic en el botón ▶ (arriba a la derecha en VS Code) o presiona Ctrl+Alt+N. Deberías ver las primeras 5 filas de la tabla en la terminal de abajo.

¿Te sale FileNotFoundError? La ruta está mal. Revisa: ¿la ruta es exactamente la de tu carpeta? ¿El nombre del archivo Excel está bien escrito? ¿Tiene la r antes de las comillas?

Leer otras hojas del Excel

El archivo tiene 5 hojas. Para leer otra hoja, solo cambia el sheet_name:

Paso 05

Conocer las columnas

La hoja Creditos tiene 19 columnas. Estas son las que van a usar para los gráficos:

Columna (nombre exacto)Qué esSirve para
Tipo_CreditoConsumo, Microcrédito, Vivienda, Comercial, Libre InversiónGráfico de barras
Estado_CreditoAl día, Mora 30, Mora 60, Mora 90, CastigadoGráfico de torta
Monto_DesembolsadoCuánto dinero se prestóHistograma, barras

Los nombres son exactos. Si escribes Tipo_credito (con c minúscula) en vez de Tipo_Credito (con C mayúscula), Python te va a dar error KeyError. Copia los nombres de la tabla de arriba.

No confundas hojas con columnas: "Asesores" es una HOJA del Excel (va en sheet_name). "Asesor" es una COLUMNA de la hoja Creditos (va entre corchetes: datos["Asesor"]).
Paso 06

Gráfico 1: Barras verticales

Crea un archivo nuevo: Archivo → Nuevo archivo → Guardar como: grafico_barras.py

import pandas as pd
import matplotlib.pyplot as plt

# Leer los datos
datos = pd.read_excel(r"C:\PROYECTO-FINAL-FINANZAS\dataset_cartera_creditos.xlsx", sheet_name="Creditos")

# Contar cuántos créditos hay de cada tipo
conteo = datos["Tipo_Credito"].value_counts()
print(conteo)

# Crear el gráfico
plt.figure(figsize=(8, 5))
plt.bar(conteo.index, conteo.values, color="#6366f1")
plt.title("Cantidad de créditos por tipo")
plt.xlabel("Tipo de crédito")
plt.ylabel("Cantidad")
plt.xticks(rotation=45)
plt.tight_layout()
plt.savefig("grafico_barras.png")
plt.show()

print("Gráfico guardado como grafico_barras.png")

Paso 10

Modelo predictivo en Julius AI

En la misma sesión de Julius, pide un modelo que prediga la columna En_Mora (Sí/No).

Ejemplo de prompt para el modelo

"Con el mismo dataset, crea un modelo predictivo que prediga la columna En_Mora (si un crédito va a caer en mora o no). Usa como variables de entrada: Monto_Desembolsado, Plazo_Meses, Tasa_Interes, Tipo_Credito, Sucursal y Calificacion_Riesgo. Muestra la precisión del modelo (accuracy), las variables más importantes, y una explicación de los resultados."

¿Cómo interpretar el resultado?

AccuracySignificadoQué decir en la sustentación
70% o másBuen modeloFunciona. Reportar qué variable pesa más y por qué tiene sentido.
55% a 70%Modelo regularCapacidad limitada. Sugerir qué datos adicionales mejorarían la predicción.
50% o menosNo predice nadaEs como lanzar una moneda. Proponer qué información falta.
Lo importante no es el número: Se evalúa que sepan interpretarlo y explicar qué significa para la cooperativa.
