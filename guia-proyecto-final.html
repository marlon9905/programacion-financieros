Paso 01

Leer el archivo Excel en Python

Lo primero que necesitan es cargar el dataset en Python. Hay dos formas de hacerlo:

Antes de empezar: Descarguen el archivo dataset_cartera_creditos.xlsx y péguenlo en la misma carpeta donde van a crear su archivo .py. Si no están en la misma carpeta, Python no va a encontrar el archivo y les va a salir error.
A
Forma simple (archivo al lado del script)

Si el archivo dataset_cartera_creditos.xlsx está en la misma carpeta que su archivo .py, solo escriben el nombre:

import pandas as pd

datos = pd.read_excel("dataset_cartera_creditos.xlsx", sheet_name="Creditos")
print(datos)
Tip: Esta es la forma más fácil. Solo funciona si el Excel y el .py están juntos en la misma carpeta.
B
Con ruta completa (si la forma simple no funciona)

Si les sale error con la forma simple, pueden usar la ruta completa del archivo. Así se hace con la ruta completa:

import pandas as pd

datos = pd.read_excel(r"C:\programacion finanzas\CLASE\dataset_cartera_creditos.xlsx", sheet_name="Creditos")
print(datos)
Importante: Pongan la r antes de las comillas (r"...") para que Python no confunda las barras \ con caracteres especiales. Y cambien la ruta por la carpeta donde ustedes tengan el archivo.
?
¿Cómo sé cuál es mi ruta?

En el Explorador de archivos de Windows, hagan clic en la barra de dirección de la carpeta donde tienen el Excel. Eso les muestra la ruta completa. La copian y la pegan en el código.

Paso 04

Ideas para los gráficos (sin resolver)

Aquí les doy la idea y la función de matplotlib que necesitan. Ustedes arman el código completo.

Gráfico de barras

Contar cuántos créditos hay por tipo y graficarlos:

# Contar por categoría
conteo = datos["Tipo_Credito"].value_counts()

# Graficar barras
plt.bar(conteo.index, conteo.values)
plt.title("Tu título aquí")
plt.xlabel("...")
plt.ylabel("...")

Gráfico de torta / pie

Mostrar la distribución porcentual por estado:

# Contar por estado
estados = datos["Estado"].value_counts()

# Graficar torta
plt.pie(estados.values, labels=estados.index, autopct="%1.1f%%")
plt.title("Tu título aquí")

Gráfico de barras horizontales

Sumar montos por sucursal:

# Agrupar y sumar
por_sucursal = datos.groupby("Sucursal")["Monto_Desembolsado"].sum()

# Barras horizontales
plt.barh(por_sucursal.index, por_sucursal.values)
plt.title("Tu título aquí")
plt.xlabel("...")

Histograma

Ver cómo se distribuyen los montos desembolsados:

# Histograma de montos
plt.hist(datos["Monto_Desembolsado"], bins=20)
plt.title("Tu título aquí")
plt.xlabel("...")
plt.ylabel("...")
Recuerden: Cada gráfico necesita plt.figure(figsize=(8, 5)) antes de graficar, colores profesionales (no los de defecto), y los nombres del grupo en el título. Guarden cada gráfico con plt.savefig("grafico1.png").

Paso 06

Dashboard en Julius AI

Para el dashboard en Julius AI, recuerden la técnica de prompts:

Estructura del prompt: Rol + Contexto + Tarea + Formato

  • Rol: "Actúa como un analista de riesgos financieros"
  • Contexto: Describir el dataset (600 créditos, cooperativa, columnas principales)
  • Tarea: Qué visualizaciones quieren (barras, torta, indicadores, tabla)
  • Formato: "Usa colores profesionales y títulos en español"
No olviden: Suban el archivo dataset_cartera_creditos.xlsx a Julius AI antes de escribir el prompt.
