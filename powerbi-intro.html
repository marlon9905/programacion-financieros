01

¿Qué es Power BI?

Power BI es una herramienta de Microsoft para crear dashboards interactivos — paneles visuales donde puedes ver gráficos, indicadores y tablas que se actualizan con tus datos.

🔍 ¿Qué es un dashboard?

Imagina el tablero de un carro: en un solo vistazo ves la velocidad, la gasolina, la temperatura. Un dashboard financiero es lo mismo pero con datos de negocio: ventas totales, gastos por categoría, tendencia del dólar, todo en una sola pantalla.

¿Por qué Power BI y no Excel?

Excel es excelente para organizar datos y hacer cálculos. Pero cuando necesitas visualizar esos datos de forma profesional e interactiva, Power BI es la herramienta correcta:

  • Interactividad: haces clic en un gráfico y los demás se filtran automáticamente
  • Diseño profesional: los gráficos se ven mucho mejor que en Excel
  • Actualización: cambias el Excel y el dashboard se actualiza solo
  • Compartir: puedes publicar tu dashboard para que otros lo vean
📊 Dato para tu hoja de vida Power BI es una de las herramientas más pedidas en ofertas laborales de finanzas, contabilidad y administración en Colombia. Saber usarlo te diferencia de otros candidatos.
02

Power BI Desktop vs Service vs App

Power BI tiene tres versiones. Nosotros vamos a usar Desktop, que es gratis:

💻
Power BI Desktop
✅ GRATIS
Se instala en tu computador. Aquí creas los dashboards. Es donde vamos a trabajar en clase.
☁️
Power BI Service
Requiere licencia
Versión web (app.powerbi.com). Sirve para publicar y compartir dashboards con tu equipo de trabajo.
📱
Power BI Mobile
GRATIS
App para celular. Sirve para ver dashboards publicados desde el teléfono. No se crean aquí.
Resumen Desktop = donde creas. Service = donde compartes. Mobile = donde consultas. Para esta clase solo necesitas Desktop.
03

Instalación de Power BI Desktop

Requisito Power BI Desktop solo funciona en Windows (Windows 10 o superior). No está disponible para Mac ni Linux.
Ir a la página de descarga

Entra a: microsoft.com/power-bi/desktop → clic en "Descargar gratis"

Ejecutar el instalador

Abre el archivo descargado (.exe) y sigue las instrucciones. Acepta los términos y dale Siguiente a todo.

Abrir Power BI Desktop

Búscalo en el menú Inicio. La primera vez te pide iniciar sesión con una cuenta Microsoft — puedes darle "Cerrar" o "Omitir", no es obligatorio para trabajar localmente.

¡Listo!

Ya puedes empezar a crear dashboards. El archivo se guarda con extensión .pbix

Alternativa: Microsoft Store También puedes buscarlo directamente en la Microsoft Store de Windows: busca "Power BI Desktop" e instálalo desde ahí. Es más fácil y se actualiza solo.
04

La interfaz de Power BI

Cuando abres Power BI Desktop, verás una pantalla con varias zonas. Estas son las más importantes:

🎨
Lienzo (centro)
Es el área blanca grande donde colocas tus gráficos. Piensa en él como una hoja en blanco donde armas tu dashboard.
📊
Panel de Visualizaciones (derecha)
Aquí eliges el tipo de gráfico: barras, línea, torta, tarjeta, mapa, etc. Solo haces clic en el ícono del gráfico que quieres.
📋
Panel de Campos (derecha, abajo)
Muestra las columnas de tu Excel. Desde aquí arrastras los campos hacia los gráficos.
🔧
Cinta de opciones (arriba)
Menú superior con botones como "Obtener datos", "Publicar", y opciones de formato.
📑
Pestañas de página (abajo)
Tu dashboard puede tener varias páginas, como las hojas de Excel. Cada pestaña es una página del reporte.
👁️
Vistas (izquierda)
Tres íconos: Informe (donde armas el dashboard), Tabla (ver los datos en filas), Modelo (relaciones entre tablas).
La idea clave

En Power BI todo funciona con arrastrar y soltar (drag & drop). Arrastras un campo del panel de Campos hacia el gráfico, y Power BI hace el resto. No escribes código, no escribes fórmulas — solo arrastras.

05

Cargar datos desde Excel

Lo primero que necesitas es conectar tu fuente de datos. Power BI puede leer Excel, CSV, bases de datos, páginas web y más. Nosotros vamos a usar un archivo Excel.

Paso a paso

Clic en "Obtener datos"

Está en la pestaña Inicio de la cinta superior, a la izquierda. Selecciona "Libro de Excel".

Seleccionar el archivo

Navega hasta tu archivo Excel y dale Abrir.

Elegir la hoja

Aparece una ventana con las hojas del Excel. Marca la que contiene tus datos (generalmente "Hoja1") y dale "Cargar".

Verificar en el panel de Campos

A la derecha deberías ver el nombre de tu tabla y debajo las columnas (Mes, Precio_Dolar, etc.).

Error común Si no aparecen tus columnas, probablemente el Excel no tiene encabezados en la primera fila. Power BI espera que la primera fila tenga los nombres de las columnas (Mes, Precio, Ventas, etc.), no datos.
Truco: "Transformar datos" En vez de "Cargar", puedes darle "Transformar datos". Esto abre el Editor de Power Query donde puedes limpiar los datos antes de usarlos: cambiar nombres de columnas, eliminar filas vacías, cambiar tipos de datos. No lo usaremos hoy, pero es muy útil.

El Excel que vamos a usar

Para esta clase, vamos a trabajar con el archivo Datos_Financieros.xlsx que tiene esta estructura:

¿No tienes el Excel? Puedes crear uno rápido: abre Excel, pon esos encabezados en la primera fila, llena 12 filas (una por mes) con datos inventados, y guárdalo. Lo importante es que tenga encabezados claros y datos numéricos.
06

Tu primer gráfico en Power BI

Ya con los datos cargados, hacer un gráfico toma 3 clics:

Elegir el tipo de gráfico

En el panel de Visualizaciones (derecha), haz clic en el ícono de Gráfico de barras agrupadas (el primero). Aparece un gráfico vacío en el lienzo.

Arrastrar el campo X

Del panel de Campos, arrastra "Mes" al área que dice "Eje X" (o "Eje" dependiendo del gráfico).

Arrastrar el campo Y

Arrastra "Ingresos" al área que dice "Eje Y" (o "Valores").

¡Listo! Ya tienes un gráfico de barras mostrando los ingresos por mes.

Compara con Python

En Python escribíamos plt.bar(meses, ingresos) y luego plt.title(), plt.xlabel(), plt.show()... En Power BI hicimos lo mismo con 3 arrastres. El resultado es similar, pero Power BI es interactivo — puedes hacer clic en las barras y explorar los datos.

Cambiar el tipo de gráfico

¿Quieres verlo como línea en vez de barras? Solo haz clic en el gráfico y luego clic en otro ícono del panel de Visualizaciones. El gráfico cambia al instante sin perder los datos.

Mover y redimensionar

  • Mover: haz clic en el gráfico y arrástralo a otra posición en el lienzo
  • Redimensionar: arrastra las esquinas o bordes del gráfico
  • Eliminar: selecciona el gráfico y presiona Suprimir (Delete)
Truco: alinear gráficos Para que tu dashboard se vea profesional, alinea los gráficos. Ve a Formato → Alinear en la cinta superior para alinear varios gráficos seleccionados.

08

Filtros y segmentadores

La magia de Power BI está en la interactividad. Hay dos formas de filtrar:

1. Filtro cruzado (automático)

Cuando haces clic en una barra de un gráfico, todos los demás gráficos se filtran automáticamente. Por ejemplo: si haces clic en "Marzo" en el gráfico de barras, la torta y la tarjeta solo muestran datos de marzo.

Esto es lo que hace especial a Power BI En Excel, cada gráfico es independiente. En Power BI, todos los gráficos están conectados. Esto te permite explorar los datos haciendo clic, sin modificar nada.

2. Segmentador de datos (Slicer)

Es un filtro visual que pones en el dashboard para que el usuario elija qué ver:

Agregar un segmentador

En Visualizaciones, busca el ícono de Segmentación de datos (parece un embudo con una lista).

Arrastrar un campo

Arrastra "Categoría" (o "Mes") al segmentador. Aparecen botones o una lista con las opciones.

Usar el filtro

Haz clic en una categoría y todos los gráficos del dashboard se filtran. Clic en otra para cambiar. Ctrl+clic para seleccionar varias.

Truco: estilo del segmentador Selecciona el segmentador → en el panel de Formato (ícono del rodillo de pintura) puedes cambiar el estilo: Lista (vertical), Mosaico (botones horizontales), o Desplegable (dropdown). Para meses, el mosaico se ve muy bien.
09

Tarjetas KPI

Las tarjetas muestran un número grande y destacado. Son perfectas para los indicadores principales de tu dashboard: ventas totales, utilidad del mes, número de clientes.

Seleccionar "Tarjeta"

En Visualizaciones, busca el ícono de Tarjeta (parece un número "123").

Arrastrar un campo numérico

Arrastra "Ingresos" al área de Campos de la tarjeta. Power BI automáticamente calcula la suma y la muestra en grande.

Cambiar el cálculo

¿Quieres el promedio en vez de la suma? Haz clic en la flecha junto al nombre del campo → cambia de "Suma" a "Promedio", "Máximo", "Mínimo", o "Recuento".

🔍 ¿Qué es un KPI?

KPI = Key Performance Indicator (Indicador Clave de Rendimiento). Son los números más importantes de un negocio. Ejemplo: "Ventas totales: $180M", "Utilidad: $42M", "Gastos promedio: $11M". Las tarjetas son la forma estándar de mostrar KPIs en cualquier dashboard.

Consejo de diseño Pon las tarjetas en la parte superior del dashboard, en fila. Así el usuario ve los números clave primero, y los gráficos detallados abajo. Es el diseño estándar en la industria.
10

Tu primer dashboard completo

Ahora vamos a armar un dashboard profesional combinando todo lo que aprendimos. El objetivo es crear algo como esto:

📐 Estructura del dashboard

Fila superior: 3 tarjetas KPI (Total Ingresos, Total Gastos, Utilidad Total)

Fila del medio: Gráfico de barras (Ingresos por mes) + Gráfico de torta (Gastos por categoría)

Fila inferior: Gráfico de línea (Tendencia de utilidad) + Segmentador (por categoría)

Paso a paso

Agregar las 3 tarjetas arriba

Crea 3 tarjetas: una con la suma de Ingresos, otra con la suma de Gastos, otra con la suma de Utilidad. Ponlas en fila en la parte superior.

Agregar gráfico de barras

Eje X = Mes, Eje Y = Ingresos. Ponlo en la mitad izquierda.

Agregar gráfico de torta

Leyenda = Categoría, Valores = Gastos. Ponlo en la mitad derecha.

Agregar gráfico de línea

Eje X = Mes, Eje Y = Utilidad. Ponlo abajo a la izquierda.

Agregar segmentador

Campo = Categoría. Estilo = Mosaico. Ponlo abajo a la derecha.

Ponerle título

Inserta un cuadro de texto (Insertar → Cuadro de texto) con el título: "Dashboard Financiero 2026". Ponlo arriba de las tarjetas.

Darle estilo profesional

  • Fondo del lienzo: Ve a Formato → Fondo de página → Color gris claro (#F2F2F2)
  • Alinear gráficos: Selecciona varios con Ctrl+clic → Formato → Alinear → Distribuir horizontalmente
  • Tema: Ve a Vista → Temas → elige uno profesional
  • Bordes redondeados: En el formato de cada gráfico, activa el borde y ponle radio
Truco final: prueba la interactividad Haz clic en una barra del gráfico de barras. ¿Ves cómo la torta, la línea y las tarjetas se actualizan? Eso es el filtro cruzado. Haz clic en el segmentador para filtrar por categoría. Este es el poder de Power BI.

Guardar tu trabajo

  • Guardar: Ctrl + S → elige ubicación → se guarda como .pbix
  • Exportar a PDF: Archivo → Exportar → PDF (genera una imagen estática del dashboard)
