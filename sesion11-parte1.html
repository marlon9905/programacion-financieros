01

Preparación

Matplotlib es una librería de Python para crear gráficos. Es como hacer gráficos en Excel, pero con código. ¿Por qué con código?

  • Automatizar: un script genera 100 gráficos en segundos
  • Reusar: cambias los datos y el gráfico se actualiza solo
  • Profesional: los bancos y fintechs lo usan para reportes automáticos

Instalar matplotlib

En la terminal de VS Code (menú Terminal → New Terminal), escribir:

terminal 
python -m pip install matplotlib

Para verificar que se instaló correctamente:

terminal 
pip show matplotlib
💡 Recuerda Solo se instala una vez. Si ya la instalaste en clases anteriores, no necesitas hacerlo de nuevo.

¿Cómo se conecta con lo que ya aprendimos?

Hasta ahora hemos aprendido a guardar datos en listas y a hacer cálculos con NumPy. Matplotlib es la pieza que falta: mostrar esos resultados de forma visual.

📦 La cadena completa LISTAS guardan los datos → NUMPY hace los cálculos → MATPLOTLIB los muestra visualmente
02

La estructura base de todo gráfico

Todos los gráficos en matplotlib siguen la misma receta. Solo cambia una línea:

mi_primer_grafico.py 
import matplotlib.pyplot as plt    # 1. Importar

plt.plot(x, y)                     # 2. Crear el gráfico
plt.title("Título")                # 3. Ponerle título
plt.xlabel("Eje X")                # 4. Nombre eje X
plt.ylabel("Eje Y")                # 5. Nombre eje Y
plt.show()                         # 6. ¡Mostrarlo!

Lo único que cambia es el paso 2, según el tipo de gráfico que queramos:

📈
Línea
Cambios en el tiempo
plt.plot()
📊
Barras
Comparar categorías
plt.bar()
🥧
Torta
Proporciones
plt.pie()
🔵
Dispersión
Relación entre variables
plt.scatter()
📶
Histograma
Distribución
plt.hist()
⚠️ Importante plt.show() abre una ventana nueva con el gráfico. Hay que cerrar esa ventana para que el programa termine. Si no la cierras, VS Code se queda esperando.

Tu primer gráfico — pruébalo ahora

Copia este código en un archivo .py y ejecútalo con Code Runner:

primer_grafico.py 
import matplotlib.pyplot as plt

plt.plot([1, 2, 3, 4, 5], [10, 20, 15, 30, 25])
plt.title("Mi primer gráfico")
plt.xlabel("Eje X")
plt.ylabel("Eje Y")
plt.show()

Debería abrirse una ventana con un gráfico de línea. ¡Felicidades, hiciste tu primer gráfico con Python!

🔍 ¿Qué significan esas dos listas?

Cuando escribimos plt.plot([1, 2, 3, 4, 5], [10, 20, 15, 30, 25]) estamos diciendo:

Primera lista [1, 2, 3, 4, 5] → Eje X (horizontal) — las posiciones de izquierda a derecha Segunda lista [10, 20, 15, 30, 25] → Eje Y (vertical) — los valores de abajo hacia arriba

Imagina una tabla:

Posición (X)Valor (Y)
110
220
315
430
525

Python dibuja un punto en cada par (x, y) y los une con una línea. Así el punto (1, 10) está a la izquierda abajo, y el punto (4, 30) está más a la derecha y más arriba.

🎯 Truco: piensa en preguntas Siempre que hagas un gráfico, piensa: ¿qué va en el eje X? (lo que quiero comparar — días, meses, productos) y ¿qué va en el eje Y? (lo que quiero medir — precios, ventas, notas). Eso te dice qué lista va primero y cuál va segundo.
03

Gráfico de línea — plt.plot()

Se usa para ver cómo cambia algo en el tiempo. Ejemplos: precio del dólar día a día, ventas por mes, precio de una acción.

Ejemplo básico: precio del dólar

dolar_semana.py 
import matplotlib.pyplot as plt

dias = ["Lun", "Mar", "Mié", "Jue", "Vie"]
dolar = [4200, 4180, 4250, 4300, 4150]

plt.plot(dias, dolar)
plt.title("Precio del dólar en la semana")
plt.xlabel("Día")
plt.ylabel("Precio (COP)")
plt.show()
🔍 ¿Qué hace cada parte?
dias = ["Lun", "Mar", ...] → Son las etiquetas del eje X (horizontal) dolar = [4200, 4180, ...] → Son los valores del eje Y (vertical) plt.plot(dias, dolar) → "Dibuja una línea usando días como X y dólar como Y"

Las dos listas deben tener el mismo tamaño. Si dias tiene 5 elementos, dolar también debe tener 5. Si no, Python te dará un error.

🎯 Truco: ¿error de tamaño? Si te sale el error x and y must have same first dimension, cuenta los elementos de cada lista. Seguro una tiene más o menos que la otra. Usa print(len(dias), len(dolar)) para verificar.

Personalizar la línea

Podemos cambiar el color, el grosor, agregar puntos y una cuadrícula de fondo:

dolar_personalizado.py 
import matplotlib.pyplot as plt

dias = ["Lun", "Mar", "Mié", "Jue", "Vie"]
dolar = [4200, 4180, 4250, 4300, 4150]

plt.plot(dias, dolar, color="blue", linewidth=2, marker="o")
plt.title("Precio del dólar en la semana")
plt.xlabel("Día")
plt.ylabel("Precio (COP)")
plt.grid(True)
plt.show()

Qué hace cada parámetro:

ParámetroQué haceEjemplo
colorColor de la línea"blue", "red", "green"
linewidthGrosor de la línea2 (normal), 3 (gruesa)
markerForma del punto"o" ● "s" ■ "^" ▲ "*" ★
plt.grid(True)Cuadrícula de fondoLíneas de referencia

Varias líneas en el mismo gráfico

Para comparar datos, escribimos plt.plot() varias veces antes de plt.show():

ingresos_vs_gastos.py 
import matplotlib.pyplot as plt

meses = ["Ene", "Feb", "Mar", "Abr", "May", "Jun"]
ingresos = [80, 85, 90, 75, 95, 100]
gastos = [60, 65, 70, 80, 72, 68]

plt.plot(meses, ingresos, marker="o", label="Ingresos")
plt.plot(meses, gastos, marker="s", label="Gastos")
plt.title("Ingresos vs Gastos (millones COP)")
plt.xlabel("Mes")
plt.ylabel("Millones COP")
plt.legend()
plt.grid(True)
plt.show()
🏷️ label y legend label="Ingresos" le pone nombre a esa línea. plt.legend() muestra el cuadrito con los nombres. Siempre que tengas varias líneas, usa label + legend.

04

Gráfico de barras — plt.bar()

Se usa para comparar categorías. Ejemplos: ventas por sucursal, gastos por área, notas por materia.

Ejemplo básico: ventas por sucursal

ventas_sucursal.py 
import matplotlib.pyplot as plt

sucursales = ["Manizales", "Pereira", "Armenia", "Medellín"]
ventas = [120, 95, 78, 145]

plt.bar(sucursales, ventas, color=["#2B6CB0", "#38B2AC", "#2B6CB0", "#38B2AC"])
plt.title("Ventas por sucursal (millones)")
plt.xlabel("Sucursal")
plt.ylabel("Ventas")
plt.grid(True, axis="y")
plt.show()
🔍 ¿Cuál es la diferencia entre plt.plot() y plt.bar()?

plt.plot() conecta los puntos con una línea — sirve para ver tendencias (sube o baja). plt.bar() dibuja rectángulos separados — sirve para comparar (cuál es más grande). Si tus datos son categorías independientes (sucursales, materias, productos), usa barras.

Opciones de color:

  • Un solo color para todas: color="orange"
  • Un color por barra: color=["blue", "green", "red", "orange"]
  • plt.grid(True, axis="y") — cuadrícula solo horizontal, se ve más limpio en barras
🎯 Truco: colores con nombre o con código Python acepta colores por nombre ("red", "blue", "green", "teal", "orange") o por código hexadecimal ("#2B6CB0"). Los hexadecimales te dan más opciones de color. Busca "color picker" en Google para encontrar el código de cualquier color.

Barras horizontales

Cuando los nombres son largos, las barras horizontales se leen mejor:

gastos_categoria.py 
import matplotlib.pyplot as plt

categorias = ["Arriendo", "Servicios", "Alimentación", "Transporte", "Entretenimiento"]
gastos = [1200000, 350000, 800000, 250000, 400000]

plt.barh(categorias, gastos, color="teal")
plt.title("Gastos mensuales por categoría")
plt.xlabel("Monto (COP)")
plt.show()
💡 plt.barh() La "h" es de horizontal. Usa plt.bar() para barras verticales y plt.barh() para horizontales.

Controlar el tamaño del gráfico

Si el gráfico sale muy pequeño o los nombres se amontonan:

grafico_grande.py 
import matplotlib.pyplot as plt

departamentos = ["Contabilidad", "Ventas", "Marketing", "TI", "RRHH", "Legal"]
empleados = [15, 22, 8, 12, 6, 4]

plt.figure(figsize=(10, 6))
plt.bar(departamentos, empleados, color="#2B6CB0")
plt.title("Empleados por departamento", fontsize=14)
plt.xlabel("Departamento")
plt.ylabel("Número de empleados")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
FunciónQué hace
plt.figure(figsize=(10, 6))Tamaño del gráfico (ancho, alto). Va ANTES de plt.bar()
plt.xticks(rotation=45)Rota los nombres del eje X para que no se amontonen
plt.tight_layout()Ajusta todo para que no se corte ningún texto
fontsize=14Tamaño de letra del título

05

Gráfico de torta — plt.pie()

Se usa para ver la proporción de cada parte dentro del total. Ejemplos: distribución de un portafolio de inversión, composición de gastos de una empresa.

Ejemplo básico: portafolio de inversión

portafolio.py 
import matplotlib.pyplot as plt

activos = ["CDT", "Acciones", "Fondo", "Cripto"]
porcentajes = [40, 30, 20, 10]

plt.pie(porcentajes, labels=activos)
plt.title("Distribución del portafolio")
plt.show()
🔍 ¿Cómo funciona plt.pie()?

A diferencia de plt.plot() y plt.bar() que necesitan dos listas (X e Y), la torta solo necesita una lista de valores. Python calcula automáticamente el porcentaje de cada porción. Si los valores son [40, 30, 20, 10], la torta se divide en 40%, 30%, 20% y 10%.

labels=activos le pone el nombre a cada porción. Sin labels, la torta sale sin etiquetas y no se sabe qué es cada pedazo.

🎯 Truco: ¿torta o barras? Usa torta cuando quieras mostrar partes de un todo (el presupuesto, la composición de algo). Si tienes más de 6 categorías, mejor usa barras — una torta con muchas porciones pequeñas se vuelve difícil de leer.

Con porcentajes visibles y personalización

portafolio_profesional.py 
import matplotlib.pyplot as plt

activos = ["CDT", "Acciones", "Fondo", "Cripto"]
porcentajes = [40, 30, 20, 10]
colores = ["#2B6CB0", "#38B2AC", "#4299E1", "#81E6D9"]
separar = [0, 0, 0, 0.1]   # separa la última porción

plt.figure(figsize=(8, 8))
plt.pie(porcentajes, labels=activos, colors=colores,
        autopct="%1.1f%%", explode=separar, startangle=90)
plt.title("Distribución del portafolio")
plt.show()
ParámetroQué hace
autopct="%1.1f%%"Muestra el porcentaje dentro de cada porción (40.0%)
autopct="%1.0f%%"Lo mismo pero sin decimal (40%)
explode=[0,0,0,0.1]Separa una porción para destacarla
startangle=90Empieza el gráfico desde arriba
colors=[...]Colores personalizados para cada porción

06

Gráfico de dispersión — plt.scatter()

Se usa para ver la relación entre dos variables numéricas. Los datos se muestran como puntos sueltos.

🔍 ¿Para qué sirve la dispersión?

Este gráfico responde la pregunta: ¿cuando X sube, Y también sube? Por ejemplo: ¿si invierto más en publicidad, vendo más? ¿Si estudio más horas, saco mejor nota? Cada punto representa un caso individual.

¿Cómo interpretar los puntos?

  • Si los puntos suben de izquierda a derecha → relación positiva (más de X = más de Y)
  • Si los puntos bajan → relación negativa (más de X = menos de Y)
  • Si están regados sin patrón → no hay relación
🎯 Truco: en finanzas esto es clave En el mundo financiero, la dispersión se usa para analizar correlaciones: ¿el precio del petróleo afecta al dólar? ¿Las tasas de interés afectan las ventas? Si ves los puntos formando una "línea diagonal", hay correlación.

Ejemplo: Riesgo vs Rendimiento

riesgo_rendimiento.py 
import matplotlib.pyplot as plt

riesgo = [2, 5, 8, 3, 7, 4, 6, 9, 1, 10]
rendimiento = [4, 10, 15, 6, 12, 8, 11, 18, 2, 20]

plt.scatter(riesgo, rendimiento, color="#2B6CB0", s=100)
plt.title("Riesgo vs Rendimiento de activos")
plt.xlabel("Riesgo (%)")
plt.ylabel("Rendimiento (%)")
plt.grid(True)
plt.show()

s=100 controla el tamaño de los puntos (s = size). Los puntos suben de izquierda a derecha, así que la relación es positiva: a mayor riesgo, mayor rendimiento.
