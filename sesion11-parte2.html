Histograma — plt.hist()

Se usa para ver cómo se distribuyen los datos. Agrupa los valores en rangos y cuenta cuántos caen en cada uno.

🔍 ¿Qué pregunta responde un histograma?

Preguntas como: ¿cuántos empleados ganan entre 2 y 3 millones? ¿La mayoría de las notas están entre 3.0 y 4.0? ¿Los rendimientos de una acción son normalmente positivos o negativos? El histograma agrupa los datos en rangos (bins) y te muestra cuántos datos caen en cada rango.

Ejemplo: distribución de salarios

distribucion_salarios.py 
import matplotlib.pyplot as plt

salarios = [1200000, 1500000, 1800000, 2000000, 1300000,
           1600000, 1900000, 2500000, 1400000, 1700000,
           1350000, 1650000, 1850000, 2200000, 1550000]

plt.hist(salarios, bins=5, color="teal", edgecolor="white")
plt.title("Distribución de salarios")
plt.xlabel("Salario (COP)")
plt.ylabel("Cantidad de personas")
plt.show()
📊 Diferencia clave A diferencia de los otros gráficos, plt.hist() recibe una sola lista. Python calcula los rangos automáticamente.

bins=5 divide los datos en 5 rangos (barras). Más bins = más detalle, menos bins = más claro. Normalmente entre 5 y 15 está bien.

Comparar dos distribuciones

comparar_rendimientos.py 
import matplotlib.pyplot as plt

ecopetrol = [2.1, 3.5, -1.2, 4.0, 0.5, 2.8, -0.3, 1.5, 3.2, -2.0, 1.8, 2.5]
bancolombia = [1.0, -0.5, 0.8, 1.5, 2.0, -1.0, 0.3, 1.2, 0.5, -0.2, 1.8, 0.7]

plt.hist(ecopetrol, bins=6, alpha=0.6, label="Ecopetrol", color="blue")
plt.hist(bancolombia, bins=6, alpha=0.6, label="Bancolombia", color="green")
plt.title("Distribución de rendimientos mensuales (%)")
plt.xlabel("Rendimiento (%)")
plt.ylabel("Frecuencia")
plt.legend()
plt.show()
💡 alpha = transparencia alpha=0.6 hace cada histograma semi-transparente (0 = invisible, 1 = sólido). Sin alpha, el segundo histograma tapa al primero y no se ve la comparación.

NumPy + Matplotlib — la combinación poderosa

Aquí es donde todo se conecta. NumPy calcula los datos y Matplotlib los grafica. Es la combinación que usan en la vida real.

🔍 ¿Por qué combinar NumPy con Matplotlib?

Hasta ahora escribíamos los datos a mano. Pero en la vida real, primero hay que calcular (promedios, rendimientos, porcentajes) y luego graficar el resultado. NumPy hace los cálculos rápido y Matplotlib los muestra bonito. Es como tener una calculadora (NumPy) y un cuaderno de gráficos (Matplotlib).

Rendimiento de acciones colombianas

rendimiento_acciones.py 
import matplotlib.pyplot as plt
import numpy as np

acciones = ["Ecopetrol", "Bancolombia", "Nutresa", "ISA", "Avianca"]
compra = np.array([2500, 30000, 25000, 18000, 4500])
actual = np.array([2850, 32000, 24000, 19500, 3800])

ganancia = actual - compra
rendimiento = (ganancia / compra) * 100

# Asignamos un color a cada acción manualmente
# Verde = ganó, Rojo = perdió (miramos si ganancia es positiva o negativa)
colores = ["green", "green", "red", "green", "red"]

plt.figure(figsize=(10, 6))
plt.bar(acciones, rendimiento, color=colores)
plt.title("Rendimiento por acción (%)")
plt.xlabel("Acción")
plt.ylabel("Rendimiento (%)")
plt.grid(True, axis="y")
plt.tight_layout()
plt.show()
💡 ¿Cómo saber qué color ponerle a cada barra? Imprime la variable ganancia con print(ganancia). Los valores positivos ganaron (verde) y los negativos perdieron (rojo). Luego escribes la lista de colores a mano, uno por cada acción.

Precio del dólar con línea de media

dolar_con_media.py 
import matplotlib.pyplot as plt
import numpy as np

dias = list(range(1, 11))
dolar = np.array([4200, 4180, 4250, 4300, 4150, 4220, 4280, 4190, 4310, 4175])

media = np.mean(dolar)

plt.figure(figsize=(10, 5))
plt.plot(dias, dolar, marker="o", color="#2B6CB0", label="Precio diario")
plt.axhline(y=media, color="red", linestyle="--", label=f"Media: ${media:,.0f}")
plt.title("Precio del dólar — 10 días")
plt.xlabel("Día")
plt.ylabel("Precio (COP)")
plt.legend()
plt.grid(True)
plt.show()
FunciónQué hace
plt.axhline(y=valor)Dibuja una línea horizontal en el valor indicado
linestyle="--"Hace la línea punteada
np.mean(datos)Calcula el promedio con NumPy

Muy útil para mostrar la media, una meta, un límite sobre los datos reales.

Torta desde datos calculados

gastos_empresa.py 
import matplotlib.pyplot as plt
import numpy as np

rubros = ["Nómina", "Arriendo", "Insumos", "Marketing", "Otros"]
gastos = np.array([15000000, 5000000, 3500000, 2000000, 1500000])

total = np.sum(gastos)

# Imprimir el total
print("Total gastos:", total)

# Graficar
plt.figure(figsize=(8, 8))
plt.pie(gastos, labels=rubros, autopct="%1.1f%%",
        colors=["#2B6CB0", "#38B2AC", "#4299E1", "#81E6D9", "#BEE3F8"],
        startangle=90)
plt.title(f"Composición de gastos — Total: ${total:,.0f}")
plt.show()

Guardar gráficos como imagen

En vez de solo mostrar el gráfico, puedes guardarlo como archivo de imagen:

guardar_grafico.py 
# Guardar como imagen:
plt.savefig("mi_grafico.png")

# Guardar Y mostrar (las dos cosas):
plt.savefig("reporte_ventas.png")
plt.show()
⚠️ Orden importante plt.savefig() debe ir ANTES de plt.show(). Si va después, guarda una imagen en blanco porque plt.show() limpia el gráfico de la memoria.

El archivo .png se guarda en la misma carpeta donde está tu archivo .py.

🎯 Truco: guardar en alta calidad Para reportes profesionales, usa plt.savefig("reporte.png", dpi=300). El parámetro dpi=300 genera una imagen en alta resolución, perfecta para imprimir o incluir en un documento Word o PDF.

Formatos disponibles

  • "grafico.png" — imagen normal, la más común
  • "grafico.jpg" — imagen más ligera pero con menos calidad
  • "grafico.svg" — vectorial, se puede ampliar sin perder calidad
  • "grafico.pdf" — ideal para incluir directamente en documentos

Errores comunes y cómo solucionarlos

Estos son los errores que más cometen los estudiantes. Si algo no funciona, revisa esta lista primero:

❌ "No module named matplotlib" No instalaste matplotlib. Abre la terminal y escribe: python -m pip install matplotlib
❌ El gráfico no aparece Olvidaste plt.show() al final. Sin esa línea, Python crea el gráfico en memoria pero no lo muestra.
❌ "x and y must have same first dimension" Tus listas tienen diferente cantidad de elementos. Si X tiene 5 elementos, Y también debe tener 5. Usa print(len(x), len(y)) para verificar.
❌ La imagen guardada sale en blanco Pusiste plt.savefig() después de plt.show(). Siempre guarda primero, muestra después.
❌ Los nombres del eje X se amontonan Usa plt.xticks(rotation=45) para rotarlos, o plt.barh() para barras horizontales. Y siempre agrega plt.tight_layout() antes de plt.show().
❌ VS Code se queda "pegado" y no responde Probablemente la ventana del gráfico está abierta atrás. Ciérrala y el programa terminará. Si sigue pegado, presiona Ctrl + C en la terminal.
